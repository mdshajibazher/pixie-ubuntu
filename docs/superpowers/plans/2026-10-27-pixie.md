# Ubuntu Pixie Implementation Plan

**Goal:** Native live screen color picker for the current Ubuntu X11 desktop.
**Architecture:** Python color helpers, ctypes libX11 capture/hotkeys, GTK UI.
**Tech Stack:** System Python 3, GTK 3, Cairo, libX11. No pip dependencies.
**Spec:** ../specs/2026-10-27-pixie-design.md

## Constraints and review focus
- Screen edges and display resizing: clip capture to the root bounds.
- Black/white/gray: correct conversions without division by zero.
- HiDPI: use physical X11 coordinates and pixel masks.
- Own window: preserve the last sampled color for copying.
- Shortcut conflicts and missing displays: visible errors, no process crashes.
